# 本地明文密码管理器

一个 Chrome Manifest V3 扩展 + Python 本地服务的组合工具：账号密码以**明文 JSON** 保存在你自己的硬盘上，手动触发填充，不联网、不上传任何数据到云端。

> ## ⚠️ 重要安全警告（务必先读）
>
> - 本工具把账号密码以**完全明文**写入硬盘 JSON 文件，任何能读取该文件的程序或人员都能看到密码。
> - **绝对不要**把 `password.json`、导出的备份文件、日志文件提交到 Git 或上传到网盘。
> - 仓库已提供 `.gitignore` 忽略这些文件，但请在执行 `git add .` 后用 `git status` 二次确认。
> - 若该文件曾被 Git 跟踪过，仅加 `.gitignore` 不够，需要先执行 `git rm --cached password.json`。
> - 本工具适合**个人自用、单机、可信环境**。公共电脑或共享环境请使用系统密钥环或正规密码管理器。
> - 项目不发布到 Chrome 应用商店，仅以「开发者模式加载已解压的扩展程序」方式使用。

## 功能特性

### 核心功能
- **表单识别**：自动识别 `input[type="password"]` 及相邻账号框，支持 SPA（Vue/React）动态渲染、ShadowDOM、iframe。
- **手动框选兜底**：识别失败时可在页面上依次点击账号框和密码框，选择结果会持久化保存。
- **保存凭证**：域名 + 用户名相同则覆盖更新，否则新增；同一网站支持多条账号。
- **手动填充**：默认不自动填充，点击列表项的「填充」才写入表单；使用原生 setter + 事件派发，兼容主流框架。
- **复制账号 / 密码**：可开启「复制密码 10 秒后自动清空剪贴板」。
- **凭证管理**：编辑、删除、全局搜索、独立管理页查看全部网站账号。
- **硬盘即数据源**：直接编辑 `password.json` 后，点插件「刷新」即可生效；插件内存不作主存储。

### 增值功能
- 密码生成器（长度、大小写、数字、符号可配置，可直接填入或保存）
- JSON 导入 / 导出备份（支持「合并」与「覆盖」两种模式）
- 备用登录链接、第二步验证码备注字段
- 排除站点黑名单
- 快捷键：`Alt+Shift+P` 打开管理器，`Alt+Shift+F` 填充（连按轮换多条账号）
- 设置页永久展示明文风险提示

## 目录结构

```
local-password-extension/
├── extension/                 # Chrome 扩展（Manifest V3）
│   ├── manifest.json          # 扩展配置与权限声明
│   ├── background.js          # 后台 Service Worker：服务代理、自动填充、剪贴板清空
│   ├── api.js                 # 通信层：所有页面经后台代理访问本地服务
│   ├── content.js             # 注入页面：表单识别、手动框选、填充
│   ├── popup.html/css/js      # 点击图标弹出的主界面
│   ├── options.html/js        # 设置页
│   ├── manage.html/js         # 全部凭证管理页
│   ├── page.css               # 设置页 / 管理页样式
│   └── icons/                 # 扩展图标（16/48/128）
└── local-service/             # Python 本地读写服务
    ├── server.py              # 仅绑定 127.0.0.1，标准库实现，无第三方依赖
    ├── start.bat              # Windows 双击启动脚本
    ├── service_config.json    # 运行时生成：端口、数据文件路径、日志开关（已被 gitignore）
    ├── password.json          # 运行时生成：明文凭证数据（已被 gitignore，绝不提交）
    └── server.log             # 运行时生成：操作日志（已被 gitignore）
```

## 快速开始

### 1. 启动本地服务

需要 Python 3（无需安装任何第三方库）。

- **Windows**：双击 `local-service/start.bat`
- ** macOS / Linux**：

```bash
cd local-service
python3 server.py
```

看到如下输出即表示正常，**窗口不要关闭**：

```
本地明文密码服务已启动
监听地址：http://127.0.0.1:8765 （仅本机可访问）
数据文件：.../password.json
```

首次启动会自动创建 `password.json`（内容为 `[]`）和 `service_config.json`。

### 2. 加载 Chrome 扩展

1. 地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目的 `extension` 文件夹

> 修改代码后，回到 `chrome://extensions` 点击该扩展的「重新加载」按钮即可生效。

### 3. 保存第一条凭证

1. 打开任意网站登录页，输入账号和密码
2. 点击浏览器工具栏中的插件图标
3. 点击「读取表单」→ 确认账号密码填写正确 → 填写备注
4. 点击「保存到硬盘」

### 4. 手动填充

1. 打开目标网站登录页
2. 点击插件图标，弹窗会自动列出该域名下的全部账号
3. 点击对应账号的「填充」
4. 确认页面已填入账号密码后，**手动点击网站的登录按钮**

> 若提示「未找到表单」，点击「手动框选」，在页面上依次点击账号框和密码框，再重新填充。

### 5. 直接修改硬盘文件

用记事本或其他编辑器修改 `password.json`，回到插件弹窗点击「刷新」，最新数据即刻生效。结构示例（**示例数据，请勿直接使用**）：

```json
[
  {
    "domain": "https://example.com",
    "title": "Example Site",
    "username": "your_name",
    "password": "your_password",
    "note": "主账号",
    "loginUrl": "https://example.com/login",
    "totp": "",
    "createTime": "2026-11-19 14:00:00"
  }
]
```

`domain` 必须与网站 origin（协议 + 域名 + 端口）完全一致，插件才会在该网站列出这条凭证。

## 配置说明

点击插件图标 → 右上角 ⚙ 进入设置页，或访问 `chrome://extensions` 中扩展的「扩展程序选项」。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 监听端口 | `8765` | 修改后需**重启本地服务** |
| password.json 路径 | 服务目录下 | 支持绝对路径，可放到其他磁盘；修改后自动创建空文件 |
| 记录读写日志 | 开启 | 日志保存到 `server.log`，不记录密码内容 |
| 自动填充 | 关闭 | 开启后页面加载完成自动填入第一条凭证，**不推荐** |
| 无痕窗口读取/保存 | 关闭 | 强烈建议保持关闭 |
| 复制密码后清空剪贴板 | 关闭 | 开启后 10 秒自动清空 |
| 显示备份提醒 | 开启 | 弹窗底部显示定期备份提示 |
| 排除站点 | 空 | 每行一个域名，支持 `*.example.com` 通配 |

快捷键可在 `chrome://extensions/shortcuts` 中修改。

## 安全设计

- 本地服务**只绑定 `127.0.0.1`**，外部网络无法访问接口。
- 插件不请求任何公网地址、不调用第三方接口。
- 密码**不会写入 `chrome.storage`**，该 API 仅保存开关、黑名单和手动框选的选择器路径。
- 无痕模式默认禁止读取和保存凭证。
- 文件写入采用「临时文件 + 原子替换」，避免写入中断导致 JSON 损坏。
- 设置页永久展示明文存储风险提示。

**仍然存在的风险**：本机上的其他程序、浏览器扩展、勒索软件或同步软件都可能读取明文 JSON。请自行评估，并定期手动备份该文件到安全位置。

## 常见问题

**Q：弹窗显示「本地服务未连接」**
A：确认 `start.bat` 窗口还在运行；若改过端口，检查设置页端口号是否与服务一致；重启服务后再试。

**Q：点击填充没反应 / 提示未找到表单**
A：部分网站表单结构非标准或位于 iframe / ShadowDOM 中。使用「手动框选」指定输入框后再填充。

**Q：改了 `password.json` 但插件看不到**
A：点击弹窗中的「刷新」按钮重新读取硬盘文件。确认 `domain` 与当前网站 origin 完全一致。

**Q：端口被占用**
A：在设置页更换端口并重启服务；或在 `local-service/service_config.json` 中修改 `port`。

**Q：如何在另一台电脑使用**
A：复制整个项目文件夹，安装 Python 3 并启动服务，再在 Chrome 中重新加载扩展；将 `password.json` 手动拷贝到新机器的服务目录（**注意传输安全，不要经过公开网盘**）。

## 本地服务接口（供了解）

服务默认监听 `http://127.0.0.1:8765`，所有响应为 JSON，含 `ok` 字段。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 健康检查、数据文件路径、凭证数量 |
| GET | `/api/credentials` | 读取全部凭证 |
| POST | `/api/credentials` | 新增或更新（body: `{credential, oldKey}`） |
| POST | `/api/credentials/delete` | 删除（body: `{key: {domain, username}}`） |
| POST | `/api/import` | 导入（body: `{items, mode: "merge"\|"overwrite"}`） |
| GET | `/api/export` | 导出全部凭证 |
| GET / POST | `/api/config` | 读取 / 修改服务配置 |
