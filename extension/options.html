设置

本地明文密码管理器 · 所有数据仅保存在你自己的硬盘上

⚠ 明文存储风险提示（永久展示）

  • 账号密码以完全明文形式保存在 JSON 文件中，任何能读取该文件的程序或人员都能直接看到密码。
  • 请勿将此文件放入网盘同步目录、共享文件夹或提交到 Git 仓库。
  • 建议定期手动复制该文件做备份，并妥善保管备份。
  • 本插件不会联网、不上传任何数据；但本机其他软件不受本插件控制。
  • 如使用公共 / 共用电脑，请放弃使用明文方案，改用系统密钥环或正规密码管理器。

本地服务

支持绝对路径；服务启动时会自检并在文件不存在时自动创建 []。修改后点「保存服务配置」。
记录读写日志
日志写入 local-service/server.log（仅记录操作类型与域名，不记录密码内容）。

插件行为

自动填充（默认关闭）
打开时，页面加载完成后自动用该域名的第一条凭证填充。出于安全考虑不推荐开启。
允许在无痕窗口读取 / 保存（默认关闭）
无痕模式下浏览器与本机其他程序仍可能记录数据，强烈建议保持关闭。
复制密码后 10 秒自动清空剪贴板
由后台服务延时执行，避免密码长期留在剪贴板中。
显示备份提醒
在弹窗底部显示「定期备份 JSON 文件」提示。
黑名单网站不自动填充、不参与快捷键填充。手动填充不受限制。

使用说明

展开查看完整流程
  1. 双击运行 local-service/start.bat，看到「本地明文密码服务已启动」即正常（窗口不要关闭）。
  2. Chrome 地址栏输入 chrome://extensions，打开「开发者模式」，点「加载已解压的扩展程序」，选择本项目的 extension 文件夹。
  3. 在登录页输入账号密码 → 点击插件图标 → 「读取表单」→ 填备注 → 「保存到硬盘」。
  4. 下次打开同一网站，点击插件图标 → 选择账号 → 「填充」→ 手动点网站登录按钮。
  5. 直接用记事本修改 password.json 后，回到插件弹窗点「刷新」即可生效。
  6. 快捷键：Alt+Shift+P 打开管理器，Alt+Shift+F 填充（多条账号时重复按可轮换）。可在 chrome://extensions/shortcuts 修改。
